# Reproducing the paper

All runs are seeded. Run the commands from the repository root. `run_queue.py` runs a job list with *N* parallel
workers, one thread each. As a guide to run time, one Phase 2 run takes about 9 minutes for 500 nodes (64² grid)
and 20 minutes for 1,045 nodes (96² grid) on one CPU thread.

## 0. Data

| data | used for | where it comes from |
|---|---|---|
| synthetic attributed graphs | Figs 2–3, Supplementary Sections S4–S5 | generated by the runners (no download) |
| Amazon product graph, Musical Instruments (2014) | Fig. 4, Supplementary Section S6 | `meta_Musical_Instruments.json.gz` from the Amazon product data of McAuley et al. (2015), placed in `data/Amazon/raw/` |

```bash
python experiments/build_amazon.py categories       # eligible node set and category counts
python experiments/build_amazon.py build            # layers S and C, attributes, labels -> data/Amazon/Musical_Instruments/
```

## 1. Runs

```bash
python experiments/make_jobs_paper.py               # writes the job lists below into results/
python experiments/run_queue.py results/jobs_planted.txt 8
python experiments/run_queue.py results/jobs_pilots.txt 8
python experiments/run_queue.py results/jobs_tax_gen.txt 8
python experiments/run_queue.py results/jobs_tax.txt 8
python experiments/run_queue.py results/jobs_fu_gen.txt 8
python experiments/run_queue.py results/jobs_fu.txt 8
python experiments/run_queue.py results/jobs_amazon.txt 8
python experiments/run_queue.py results/jobs_estimators.txt 1
```

| job list | content |
|---|---|
| `jobs_planted.txt` | planted disagreements: seeds 301–320, cross-entropy and squared-error objectives, block designs |
| `jobs_pilots.txt` | development pilots: twist seeds 900–902 (including the longer budget), tax seeds 951–953 |
| `jobs_tax_gen.txt`, `jobs_tax.txt` | the tax experiment: graphs of seeds 601–612, κ ∈ {0, 1, 1.5, 2}; tax and twist of each graph |
| `jobs_fu_gen.txt`, `jobs_fu.txt` | further analyses of the tax: area-free warps, degree-preserving twins, degree-corrected decoders, equal total dimension |
| `jobs_amazon.txt` | product network: ten Phase 1 seeds × two layers × {twist, bootstrap}; popularity-only attributes |
| `jobs_estimators.txt` | geodesic estimators against a reference solver |

## 2. Analyses

```bash
python experiments/aggregate_twist.py --tag twist   # planted disagreements -> results/synthetic/twist/summary.json
python experiments/analyze_global_tax.py            # tax experiment -> results/synthetic/globaltax/analysis_d2.json
python experiments/tax_followups.py truth
python experiments/tax_followups.py aggregate       # -> results/synthetic/globaltax_followups/aggregate.json
python experiments/analyze_amazon.py                # product network -> results/amazon/analysis.json
python experiments/analyze_amazon.py --loo          # leave one pair out -> results/amazon/loo_pairs.json
```
